KEY DATA FLOWS:
═══════════════

1. FILE CHANGE FLOW:
   File Change → File Watcher → EventBridge → Services → Database Updates → User Notifications

2. SEARCH QUERY FLOW:
   User Query → API Gateway → Search Engine → Vector DB + PostgreSQL → Ranked Results

3. DOCUMENTATION FLOW:
   Code Analysis → EventBridge → Doc Generator → S3 Storage → Search Index Update

4. REAL-TIME PROCESSING:
   EventBridge → SQS → Lambda Processors → Database Updates → Notifications

ARCHITECTURE BENEFITS:
═════════════════════

✅ Microservices: Independent scaling and deployment
✅ Event-Driven: Loose coupling and resilience
✅ Multi-Database: Optimized for different data types
✅ Serverless Processing: Cost-effective and auto-scaling
✅ Managed Services: Reduced operational overhead
✅ Security: Multi-layered security approach
✅ Monitoring: Comprehensive observability
✅ CI/CD: Automated deployment pipeline
